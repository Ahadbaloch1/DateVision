Four grades, one consistent standard

The model studies colour, surface texture, ripeness, shape and visible defects, then assigns every date to exactly one category.

From photo to grade in four steps

The same pipeline runs in training and in every prediction, so results stay consistent across batches, places and people.

Capture

Take a smartphone photo or upload an image. Different lighting, backgrounds and angles are supported.

Preprocess

The image is resized to 224 × 224 pixels, normalized and cleaned with noise reduction. HSV conversion can strengthen colour features.

Classify

A convolutional neural network built in PyTorch, using transfer learning from ResNet50 or MobileNetV3, scores each of the four grades. Results below the confidence threshold are flagged for review instead of being graded.

Explain

Grad-CAM heatmaps highlight the regions that influenced the decision, so a person can verify each result.

Built for real conditions

  • Augmentation: rotation, flipping, scaling, brightness and contrast changes, and random cropping.
  • Class imbalance handled with class weights, oversampling and balanced batch sampling.
  • Fairness across grades checked with macro-averaged metrics.
  • Lightweight MobileNetV3 option for near-real-time inference.

A dataset built for Mozawati dates

No large, labelled Mozawati dataset exists, so the project builds its own from photographs taken under real-world conditions. Every image is labelled and verified by hand.

Collected with variation in

  • Lighting: bright, shadowed and natural light
  • Backgrounds: trays, market surfaces, plain backgrounds and hands
  • Viewing angles: top, side and close-up
  • Distance: close range and normal range

Why it matters

A model trained on varied images learns the features that truly separate the grades, instead of memorizing one background or lighting setup. Dataset size and class balance are evaluated as part of the research.

About the research

An Intelligent Deep Learning Framework for Automated Mozawati Date Quality Classification. Final year project, Department of Computer Science, University of Makran Panjgur.

Objectives

Model performance

Build a CNN that classifies Mozawati dates into the four grades with a target overall accuracy of 85% or higher.

Class-wise measurement

Evaluate precision, recall and F1-score for each class and check that performance is balanced across all four grades.

Feature effectiveness

Analyze how colour, texture, ripeness, shape and surface defects influence predictions, using Grad-CAM and feature visualization.

Real-time performance

Measure inference speed in frames per second to judge suitability for real-time or near-real-time grading.

Dataset effectiveness

Develop a custom dataset of about 4,000 images and study how its size and class distribution affect accuracy and generalization.

Known limitations and how we plan for them

Limited Mozawati data

A custom dataset is collected under diverse conditions, and augmentation expands its variety.

Visual features only

The system focuses on strong external indicators. Taste, aroma and moisture cannot be assessed from images.

Lighting, background and angle

Images are collected in multiple real-world conditions, then normalized and augmented for robustness.

Limited Colab hardware

MobileNetV3, mixed precision, smaller batches and checkpoint saving keep training reliable.

Class imbalance

Weighted loss, oversampling, targeted augmentation and macro F1-score keep every grade fairly represented.
